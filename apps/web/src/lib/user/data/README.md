# University registry

`world-universities.json` is a minimized copy of Hipo's
[World University Domains and Names](https://github.com/Hipo/university-domains-list).
It contains only `name`, `country`, `alpha_two_code`, and `domains`.

The registry provides canonical search and domain matching. A selection remains
unverified until the user completes the email OTP flow. Reviewed exceptions to
the SWOT abuse list live in `../profile.ts`; do not bypass that list broadly.
